## Descripción del dataset: Casas en Toluca

El conjunto de datos **`Casa_toluca.csv`** contiene **2,004 registros y 8 variables** relacionadas con casas en venta en Toluca, Estado de México. Incluye información sobre la ubicación, el área, el número de baños, las habitaciones y el precio de las propiedades. Permite analizar el mercado inmobiliario e identificar relaciones entre las características de las viviendas y su valor. Se recomienda realizar una limpieza previa, ya que existen columnas de índices redundantes y algunos datos faltantes.

### Lista de variables

| Variable | Descripción |
|---|---|
| `Unnamed: 0.2` | Índice consecutivo generado al guardar los datos. |
| `Unnamed: 0` | Índice adicional del conjunto de datos. |
| `Unnamed: 0.1` | Otro índice generado durante el procesamiento. |
| `Ubicación` | Dirección o ubicación de la propiedad. |
| `Area` | Superficie de la vivienda. |
| `Baños` | Número de baños de la propiedad. |
| `Habitaciones` | Número de habitaciones de la vivienda. |
| `Precio` | Precio de venta de la propiedad. |

### Observaciones

- **Registros:** 2,004 propiedades.
- **Variables útiles para el análisis:** `Ubicación`, `Area`, `Baños`, `Habitaciones` y `Precio`.
- **Limpieza recomendada:** eliminar las tres columnas de índices si no aportan información relevante y revisar los valores faltantes.
- **Posibles análisis:** distribución de precios, relación entre área y precio, y comparación de precios según el número de habitaciones y baños.
